# 行业分析 playbooks：关键量价与护城河指标

触发后从本文件选择 1-2 个最贴近的行业，不能机械套全部指标。每一项标注公司是否披露、数据期和来源，优先同行可比口径。市场规模采用自上而下/自下而上双重校验，避免拿宏观总市场替代公司可服务市场。

| 赛道 | 业务/前瞻指标 | 财报质量与估值驱动 | 结构性风险 |
|---|---|---|---|
| 白酒/食品饮料 | 价盘、动销、渠道库存、经销商数量、合同负债、产品结构 | 收入/销量价差、毛利、现金回款、品牌提价权；PE/DCF | 渠道压货、批价下滑、消费需求 |
| 连锁咖啡/餐饮 | 门店净增、同店销售、单店杯量/客单、会员复购、外卖佣金 | 单店毛利、EBITDA、成熟店回本周期、加盟质量、SOTP | 补贴战、关店率、食品安全 |
| AI 算力/服务器 | 国内外订单、交货周期、GPU/算力供给、机架上架率、网络带宽 | 订单转收入、存货/应收、研发投入、毛利率、现金流 | 出口管制、供应受限、客户集中、价格战 |
| 半导体/设备 | 产能利用率、良率、晶圆/设备出货、国产替代、订单覆盖 | 研发资本化、折旧、毛利率、库存周转、中周期 EV/EBITDA | 周期波动、技术路线、管制 |
| 新能源/锂电/光伏 | 装机/排产、ASP、成本曲线、库存、产能开工、海外出货 | 单位盈利、ROIC、capex、现金流、减值风险 | 产能过剩、贸易壁垒、补贴退出 |
| 汽车/汽车零部件 | 月度批发/零售、车型结构、出口、订单、产能 | 单车 ASP/毛利、研发、保修、渠道库存 | 价格战、召回、关税、智能化投入 |
| 软件/SaaS | ARR、净留存 NRR、付费用户、ARPU、续费率、合同负债 | 毛利/研发/获客回本期、经营现金流、递延收入 | 收入确认、用户质量、价格竞争 |
| 互联网平台 | MAU/DAU、转化率、GMV 与实际收入 take rate、付费率 | 广告加载、费用效率、现金流、监管成本 | 反垄断、平台规则、获客成本 |
| 银行 | 净息差 NIM、存贷增速、不良率 NPL、拨备覆盖、核心一级资本充足率 | ROE、信贷成本、存款成本、PB-ROE、剩余收益 | 资产质量、利率、资本补充 |
| 保险 | 新业务价值 NBV、保费结构、投资收益、偿付能力 | 内含价值 EV（与市场价值区分）、营运偏差 | 久期错配、利差损 |
| 医药/创新药 | 临床阶段、入组、里程碑付款、集采政策、医保准入 | rNPV、研发费用、专利期限、销售峰值 | 研发失败、政策降价、适应症竞争 |
| 资源/周期品 | 商品现价/长协价、单位现金成本、产能/库存、开采量 | 中周期利润、现金成本/吨、capex、NAV | 商品周期、环保、地缘供应 |
| 公用事业 | 发电/供水量、利用小时、上网电价、调价机制 | 股息覆盖率、资产期限、融资成本 | 监管定价、资本强度 |

## 指标如何与同行合理比较
1. 同口径：相同业务地区、季节、价格税费、直营/加盟口径、订阅付费定义等。
2. 竞争变化：龙头大跌时检查是否仅估值压缩、其订单是否丢失、终端需求是否下滑，以及目标公司是否抢到份额。
3. 没有可靠运营 KPI，不要拿搜索指数/社媒声量当成真实用户或订单；只能做领先代理指标，注明局限。
4. 对政策密集型行业至少建立“有效规则—草案—地方试点—执行力度”四栏，与实际盈利路径一一映射。
